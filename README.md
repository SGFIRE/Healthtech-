
# 🌐 DePIN Medical AI Network

A decentralized, community-governed AI-powered healthcare analysis platform built on DePIN (Decentralized Physical Infrastructure Network) principles.

![DePIN Medical AI](https://img.shields.io/badge/DePIN-Medical%20AI-blue) ![License](https://img.shields.io/badge/license-MIT-green) ![Python](https://img.shields.io/badge/python-3.8+-blue)

## 🚀 Features

- **🏥 AI-Powered Medical Analysis**: Advanced AI analysis with multiple specialist perspectives
- **🌐 Decentralized Network**: Distributed infrastructure with consensus mechanisms
- **🗳️ Community Governance**: Token-based voting and proposal system
- **🎓 Distributed Learning**: Community-driven model improvements
- **🔗 Blockchain Integration**: Secure, immutable medical record storage
- **💰 Incentive System**: MEDAI token rewards for contributions
- **🎤 Voice Integration**: Audio input and report generation
- **📧 Report Sharing**: Email integration for medical reports

## 🏗️ Architecture

This platform implements a full DePIN stack:

- **Network Layer**: Distributed nodes with consensus mechanisms
- **Governance Layer**: DAO-style community governance
- **Incentive Layer**: Token economics and reputation system
- **Application Layer**: Medical AI analysis interface
- **Storage Layer**: Blockchain-based data persistence

## 🛠️ Installation

### Prerequisites

- Python 3.8+
- Node.js (for blockchain components)
- FFmpeg (for audio processing)

### Quick Start

1. **Clone the repository**
```bash
git clone https://github.com/SGFIRE/depin-medical-ai.git
cd depin-medical-ai
```

2. **Install dependencies**
```bash
pip install -r requirements.txt
```

3. **Set up environment variables**
```bash
cp .env.example .env
# Edit .env with your API keys
```

4. **Run the application**
```bash
python app.py
```

### Docker Installation

```bash
docker-compose up -d
```

## 🔧 Configuration

Create a `.env` file with the following variables:

```env
GOOGLE_API_KEY=your_google_ai_api_key
GMAIL_USER=your_gmail_address
GMAIL_APP_PASSWORD=your_gmail_app_password
DEPIN_NETWORK_ID=main
BLOCKCHAIN_ENDPOINT=localhost:8545
```
